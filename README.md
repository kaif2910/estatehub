# EstateHub - AI Mode 🏡✨

**Live Demo:** [https://estatehub-production-f9c0.up.railway.app/](https://estatehub-production-f9c0.up.railway.app/)

EstateHub is a modern, AI-powered real estate marketplace platform that seamlessly connects buyers, sellers, and brokers. Built with a robust Java Servlet backend and an Optimistic UI frontend, it delivers blazing-fast performance and an exceptional user experience.

## Features
* **AI Mode Recommendations:** Smart algorithms to match users with their perfect property.
* **Optimistic UI:** Instant visual feedback for liking and removing properties.
* **Advanced Connection Pooling:** Uses HikariCP for 5ms database query response times.
* **Secure Auth:** BCrypt password hashing and OTP verification.
* **Role-based Dashboards:** Dedicated experiences for Customers, Brokers, Sellers, and Admins.
